# Демо-коллекция: 10 клонов популярных сервисов

Blueprint для [Render](https://render.com) — разворачивает все 10 приложений
в один клик. Каждое приложение — самостоятельный Node-сервер (SQLite + WebSocket)
из своего репозитория.

## Деплой

Кнопка **Deploy to Render** (или вручную: Render → New → Blueprint → выбрать
этот репозиторий). Render спросит доступ к репозиториям `clone-*` — разрешить.

После деплоя каждое приложение получает адрес `https://<имя>.onrender.com`.

Free-инстансы засыпают после ~15 минут простоя: первый запрос просыпается
за 30–60 секунд. Это нормально для демо.

## Приложения

| Сервис | Что это |
|---|---|
| demo-monkeytype | Тренажёр печати: WPM/точность, лидерборд, гонки по коду комнаты |
| demo-discord | Серверы, каналы, ЛС, presence, голосовые комнаты (WebRTC mesh) |
| demo-notion | Блочный редактор: дерево страниц, slash-команды, drag-n-drop |
| clone-spotify-demo | Плеер: загрузка треков, плейлисты, лайки, персистентный плеер |
| demo-excalidraw | Бесконечный холст: фигуры, зум/пан, мультиплеер |
| demo-jira | Канбан: кастомные статусы, эпики, спринты, активность |
| demo-reddit | Комьюнити, посты, вложенные комментарии, голоса, сортировки |
| demo-splitwise | Группы, траты (равные/процентные/точные, интервалы), долги |
| demo-pastebin | Подсветка синтаксиса, TTL с burn-after-read, форки, версии |
| demo-calendly | Слоты, буферы, таймзоны, .ics |

## Репозитории

Код каждого приложения: `github.com/Snowxdxaxd/clone-<имя>`
